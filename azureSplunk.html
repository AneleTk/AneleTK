Microsoft Azure-to-Splunk SIEM Pipeline Integration

Home

Implemented an end-to-end pipeline integrating Azure activity logs and security alerts into Splunk Enterprise SIEM for centralized monitoring and analysis. This involved configuring Azure Event Hubs to stream logs, setting up appropriate IAM roles and permissions, and creating consumer groups to manage data flow into Splunk. The integration enabled real-time visibility into Azure security events within the SIEM platform, enhancing threat detection and response capabilities. The logs collected are about an Azure Infrastructure itself. e.g Who started a VM, who changed a Network Security Group, who created a new resource, etc.

Technical Architecture:

- SIEM: Splunk Enterprise
- Cloud Platform: Microsoft Azure
- Data Transport: Azure Event Hubs (Standard Tier)
- Data Storage: Azure Blob Storage (Cold Tier)
- Data Ingestion: Splunk Add-on for Microsoft Cloud Services
- Security Monitoring: Microsoft Defender for Cloud (Foundational CSPM)

Key Challenges and Solutions

Challenge Solution
Limited Consumer Groups causing errors and connection drops Upgraded to Event Hubs Standard Tier to enable dedicated Consumer Groups and allow Splunk Add-on to maintain an exclusive connection.
Persistence and State Configured Azure Blob Storage for checkpointing, ensuring Splunk resumes data collection from the exact last event after a restart or failure, preventing data loss and duplication.

Implementation Steps:

- Identity Management: Created an Azure App Registration and granted scoped RBAC permissions to allow Splunk to read Event hub data and write to Storage.
- Streaming Infrastructure: Provisioned an Event Hub Namespace and specific hub. Configured a dedicated "splunk-final" Consumer Group to ensure exclusive throughput.
- Logging Configuration: Established a Subscription-level Diagnostic Setting configuration to capture Security, Administrative, ServiceHealth, and Policy logs.
- Splunk Integration: Configured the Splunk Add-on for Microsoft Cloud Services, mapping the Event Hub FQDN and Storage Account for checkpointing.
- Visualization: Built a custom Splunk Dashboard to monitor event distribution by category.

Microsoft Azure is quite overwhelming at first, but it is clear that the work is scalable and becomes easier as you go along. This project was quite difficult for me, however, the skills and experience gained made it well worth it.
