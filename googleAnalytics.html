Google Analytics for Portfolio Monitoring

Home

I deployed Google Analytics for this portfolio in order to monitor visitor activity and page access.

The objectives were to:
- Create a Google Analytics account and produce a tracking code
- Create a Google Ads account and link it to Google Analytics
- Write the Google Analytics tracking code on the website
- Verify real-time telemetry in the Google Analytics dashboard
- Confirm page-level tracking by accessing different pages and observing the corresponding data in the dashboard
- Validate events (e.g page_view, scroll, etc)

With these insights, I aim to make informed decisions to optimize the user experience, improve content, and enhance the overall performance of my portfolio.
